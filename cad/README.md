# CAD

Code that generates Microdog's printed parts, written in [build123d](https://github.com/gumyr/build123d). **Empty for now**: parts arrive here one at a time, after each one is approved and test-printed. The process and current progress are in [`docs/cad-plan.md`](../docs/cad-plan.md).

When parts land, each will have:

- a script that generates it, with every dimension's source noted
- exported STL and STEP files, so you can print without running code
- a preview render
